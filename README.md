# thread-bot

Telegram-бот: присылаешь ссылку на твит из X, получаешь тред в Markdown, PDF, Word или страницей Telegraph (читается прямо в Telegram).

Работает целиком на Cloudflare (бесплатный тариф). Российский сервер не участвует, поэтому ограничение в 16 КБ и блокировка X в России на бота не влияют.

## Как устроено

1. Telegram сам присылает сообщение на Cloudflare (адрес `/webhook`).
2. Бот берёт твиты у бесплатного FxTwitter и идёт от присланного твита вверх, к началу треда, пока автор отвечает сам себе.
3. Показывает автора, число твитов и кнопки форматов.
4. Markdown и Word собираются прямо на Cloudflare. PDF делает встроенный браузер Cloudflare. Страница Telegraph создаётся через сервис Telegraph.

Пользоваться может только один человек: номер задаётся в `ALLOWED_USER_ID`, остальным бот не отвечает.

## Ограничения

* Лучше присылать ссылку на **последний** твит треда. От первого твита бот вниз не пойдёт.
* Не больше 40 твитов за раз (лимит бесплатного Cloudflare: 50 внешних запросов на одно действие).
* PDF: 10 минут работы браузера Cloudflare в сутки, этого хватает на несколько десятков файлов.
* В Word картинки и видео идут ссылками, в PDF и Telegraph картинки встраиваются.
* FxTwitter неофициальный. Если X его закроет или он начнёт блокировать адреса Cloudflare, бот перестанет собирать треды, пока не подключим другой источник.

## Настройка (один раз)

### 1. Подключить репозиторий к Cloudflare
Workers & Pages → Create → Import a repository (импорт из GitHub) → выбрать `thread-bot`. Остальное по умолчанию. После этого каждое изменение в репозитории разворачивается само.

### 2. Секреты
Workers & Pages → `thread-bot` → Settings → Variables and Secrets. Добавить как **Secret** (секрет):

| Имя | Что вписать |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather |
| `WEBHOOK_SECRET` | любая придуманная строка из латинских букв и цифр, 20–40 символов |
| `ALLOWED_USER_ID` | пока не заполнять, см. шаг 4 |
| `CF_ACCOUNT_ID` | ID аккаунта Cloudflare (справа на главной странице панели, Account ID) |
| `CF_API_TOKEN` | ключ доступа Cloudflare с правом Browser Rendering, см. ниже |

Ключ для PDF: My Profile → API Tokens → Create Token → Create Custom Token → Permissions: Account → Browser Rendering → Edit → создать и скопировать.

### 3. Включить бота
Открыть в браузере:
`https://thread-bot.<ваш-поддомен>.workers.dev/setup?key=<WEBHOOK_SECRET>`
В ответе должно быть `"ok": true`.

### 4. Закрыть бота от посторонних
Написать боту что угодно. Он ответит вашим номером в Telegram. Вписать этот номер в секрет `ALLOWED_USER_ID`.

### 5. Хранилище (по желанию, но лучше сделать)
Storage & Databases → KV → Create → имя `thread-bot` → скопировать ID. Вписать ID в `wrangler.toml` вместо `ВСТАВИТЬ_ID` и убрать решётки у трёх строк. Без хранилища бот работает, но на каждую кнопку заново скачивает тред.

## Проверка без сети

```
node test/run.js
```
Подменяет FxTwitter, Telegram, Telegraph и Cloudflare и проверяет весь путь: разбор ссылок, сборку треда, кнопки, все форматы, защиту от чужих.
